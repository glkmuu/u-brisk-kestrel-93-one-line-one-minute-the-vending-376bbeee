One pickup line, 200 characters at most, as if a vending machine were flirting with a passing human:

> Hey — my coils have been spinning since you walked in, and exact change never looked this good. Press B7, cutie, I only jam for you.

The line is spoken by the machine itself, in its own world — coils, exact change, button B7 — and the punch lands in the last few words: a vending machine that only jams for you. Short, speakable in one breath, cheeky and warm rather than creepy.

`main.py` (Python 3.13, standard library only) reads `entry.txt`, validates the gate (UTF-8, 1–200 characters, exactly one line, not only whitespace), and writes it byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no dependencies, deterministic — same run, same bytes.
